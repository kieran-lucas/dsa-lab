# Sum of Two Numbers

Given two integers **a** and **b**, print their sum.

This small problem is a good place to check your environment and explore different approaches.

## Input

A single line containing two space-separated integers, `a` and `b`.

## Output

Print one integer: the value of `a + b`.

## Constraints

- −10⁹ ≤ a, b ≤ 10⁹
- Use a signed integer type that can hold the sum.

## Example 1

Input
```text
2 3
```

Output
```text
5
```

## Example 2

Input
```text
-8 3
```

Output
```text
-5
```

> Whitespace between output tokens does not affect the verdict.
